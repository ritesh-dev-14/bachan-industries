# Bachan Industries website

React + Vite + JavaScript + Tailwind CSS + Framer Motion. Includes Home, About, Products and Contact pages.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code / terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Build
```bash
npm run build
npm run preview
```

## Notes
- The contact form opens the visitor's default email application with a prefilled email to bachancnc@gmail.com. It does not submit to a backend.
- Product photos are remote Unsplash images; replace them with Bachan Industries' actual machine photos before production.
- The supplied logo is included as `Bachan.png`.
- Update phone numbers, product specifications, social links and company copy as needed before publishing.
